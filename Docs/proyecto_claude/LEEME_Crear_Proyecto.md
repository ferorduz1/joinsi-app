# Cómo crear el proyecto "JoinSi · CEO de producto"
**Para:** Fernando · **Tiempo:** unos 5 minutos · **Decidido:** 2026-10-27

## Por qué un proyecto aparte
El proyecto "CEO Agéntico" está al 98% de su capacidad de conocimiento, sus instrucciones hablan de la división completa y su búsqueda mezcla temas de realtors, scoring y playbooks. JoinSi necesita instrucciones propias, memoria propia y espacio para crecer. El canon no se mueve: sigue en `C:\Joinsi\Docs`.

## Pasos
1. En claude.ai, crea un proyecto nuevo llamado **JoinSi · CEO de producto**.
2. En las instrucciones del proyecto, pega completo el texto de `Docs/proyecto_claude/INSTRUCCIONES_Proyecto_JoinSi_CEO.md`.
3. Sube estos tres archivos como conocimiento del proyecto (son espejos para cuando un chat no tenga acceso al folder):
   - `Docs/00_LEEME_ARRANQUE_ARQUITECTO.md`
   - `Docs/JOINSI_Memoria_LTM_Proyecto.md`
   - `Docs/JOINSI_Contexto_HOMESI.md`
4. Abre una sesión de Cowork dentro de ese proyecto con la carpeta `C:\Joinsi` conectada.
5. Pega el prompt de arranque que está en la sección 9 de `Docs/00_LEEME_ARRANQUE_ARQUITECTO.md`.

## Mantenimiento
- Cuando el CEO te diga que la LTM o el contexto cambiaron mucho, reemplaza esos espejos en el proyecto.
- El proyecto "CEO Agéntico" conserva un puntero que dice dónde vive JoinSi. No hace falta borrar nada de allá.
- Si tomas una decisión de HOMESÍ en otro proyecto que afecte a JoinSi (por ejemplo, la compensación del LO), cuéntasela al CEO de JoinSi para que actualice el contexto.
